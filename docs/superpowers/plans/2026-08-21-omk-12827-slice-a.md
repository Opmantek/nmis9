# OMK-12827 Slice A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop `NMISNG::Util`'s encryption control from disabling itself or rewriting stored secrets to cleartext, and make it fail closed instead.

**Architecture:** Three edits to `lib/NMISNG/Util.pm` (the four self-disable branches, the latent cleartext write-back in `encrypt`, and four stale comments), plus one new behavioural test that forces the crypto modules absent and proves no config write is attempted and the affected value fails closed.

**Tech Stack:** Perl 5, `Test::More`, `Test::Without::Module` (now in the dev/CI image per PR #61), `NMISNG::Util`, `NMISNG::Log`.

**Spec:** `docs/superpowers/specs/2026-08-21-omk-12827-slice-a-design.md`.

## Global Constraints

- Changes confined to `lib/NMISNG/Util.pm` and the new test. No other product files.
- No code path may write `global_enable_password_encryption`. On any path.
- `encrypt` must never emit cleartext for a stored `"!!"` value and must never write the config.
- Fail closed by returning the existing `""` sentinel, never by `die`. A non-encrypted value that needs no decryption passes through unchanged.
- The enable-boundary failure (`verifyNMISEncryption`) must `print` an actionable message that names the three Perl modules and the OS packages.
- The regression test must fail, never skip, if `Test::Without::Module` is unavailable.
- Booleans via `NMISNG::Util::getbool`. Do not use the `-truth` flag.
- Branch `sec/OMK-12827-core`, base `origin/nmis9_sec`, one pull request into `nmis9_sec`.

## File Structure

- `lib/NMISNG/Util.pm` — modify. `decrypt` (~4714), `encrypt` (~4848), `verifyNMISEncryption` (~4470), and four comment sites (~4473, ~4752, ~4886, ~4964).
- `test/t_util_encryption_failclosed.t` — create. Drives `NMISNG::Util` directly, no Mongo, no NMISx.
- `ci/scripts/perl_tests.sh` — modify. Add the new test filename to the `working_tests` array.

### Task 1: Item 1 — the control never disables itself, and fails closed

**Files:**
- Create: `test/t_util_encryption_failclosed.t`
- Modify: `ci/scripts/perl_tests.sh` (register the test)
- Modify: `lib/NMISNG/Util.pm` (`decrypt`, `encrypt`, `verifyNMISEncryption` module-missing branch)
- Test: `test/t_util_encryption_failclosed.t`

**Interfaces:**
- Consumes: `NMISNG::Util::decrypt($password, $section, $keyword)`, `NMISNG::Util::encrypt($password, $section, $keyword, $force)`, `NMISNG::Util::verifyNMISEncryption(log => $logger)`, `NMISNG::Util::testEncryption()`, `NMISNG::Util::loadConfTable()`, `NMISNG::Util::getbool()`.
- Produces: nothing for later tasks. Self-contained.

**Why this test design.** The config flag is set through the `NMIS_*` env override (`NMIS_GLOBAL_ENABLE_PASSWORD_ENCRYPTION=true`, `_apply_env_overrides` layer 4), so `loadConfTable` reports encryption enabled and the code enters the crypto branch. `Test::Without::Module` forces `require Crypt::CBC` and friends to fail on demand, independent of the host. The old code reacted by calling `writeConfData` to persist the flag as `"false"`; the new code must not. A spy that replaces `NMISNG::Util::writeConfData` records whether any write was attempted, so the test needs no on-disk config and cannot leave anything reconfigured. Note that `writeConfData` itself now refuses to persist an ENV-sourced key (`Util.pm:2143-2151`), which is exactly why an env-only, no-spy test would falsely pass, so the spy is what makes the regression visible.

- [ ] **Step 1: Write the failing test**

Create `test/t_util_encryption_failclosed.t`:

```perl
#!/usr/bin/perl
#
# OMK-12827 Slice A: NMISNG::Util's encryption control must never disable itself
# and must fail closed when the crypto modules are unavailable.
#
# With encryption enabled and Crypt::CBC/Crypt::Cipher::AES/Math::Random::Secure
# forced absent, the old code logged, set global_enable_password_encryption to
# "false", wrote the config back, and returned the input. The fix: never write
# the flag, and return "" for a value that cannot be produced.
#
# The flag is set via the NMIS_* env override (in memory, layer 4), so nothing
# on disk changes. writeConfData is replaced by a spy, so the test proves no
# config write is even attempted and touches no files. Crypt modules are forced
# absent with Test::Without::Module, so the branch is exercised on any host.

use strict;
use warnings;
use FindBin;
use lib "$FindBin::Bin/../lib";

# Must be set before any config load so loadConfTable sees encryption enabled.
BEGIN { $ENV{NMIS_GLOBAL_ENABLE_PASSWORD_ENCRYPTION} = 'true'; }

use Test::More;

# Fail, never skip. If we cannot force the modules absent, the regression cannot
# be exercised and the suite must go red, not quietly green.
BEGIN {
	eval { require Test::Without::Module; Test::Without::Module->import(
		qw(Crypt::CBC Crypt::Cipher::AES Math::Random::Secure)); 1 }
		or BAIL_OUT("Test::Without::Module is required to run this test and is not installed: $@");
}

use NMISNG::Util;
use NMISNG::Log;

# Sanity: the modules really are hidden now.
ok(!eval { require Crypt::CBC; 1 }, "Crypt::CBC is forced absent for this test");

# Confirm the code sees encryption as enabled through the env override.
my $conf = NMISNG::Util::loadConfTable();
ok(NMISNG::Util::getbool($conf->{global_enable_password_encryption}),
	"encryption is enabled in the effective config (via NMIS_* override)");

# Spy on writeConfData: record every call, perform no write.
my @writes;
{
	no warnings 'redefine';
	*NMISNG::Util::writeConfData = sub { push @writes, {@_}; return; };
}

my $logger = NMISNG::Log->new(level => 'info', path => undef);

# --- decrypt ---
@writes = ();
is(NMISNG::Util::decrypt('!!deadbeefciphertext'), "",
	"decrypt of a '!!' value returns '' when crypto is unavailable");
is(scalar(@writes), 0, "decrypt attempted no config write");

@writes = ();
is(NMISNG::Util::decrypt('plainvalue'), 'plainvalue',
	"decrypt of a non-encrypted value passes it through unchanged");
is(scalar(@writes), 0, "decrypt of plaintext attempted no config write");

# --- encrypt ---
@writes = ();
is(NMISNG::Util::encrypt('secretplaintext'), "",
	"encrypt of a plaintext value returns '' when crypto is unavailable");
is(scalar(@writes), 0, "encrypt attempted no config write");

@writes = ();
is(NMISNG::Util::encrypt('!!alreadyencrypted'), '!!alreadyencrypted',
	"encrypt of a '!!' value returns it unchanged, never cleartext");
is(scalar(@writes), 0, "encrypt of a '!!' value attempted no config write");

# --- testEncryption ---
is(NMISNG::Util::testEncryption(), 0,
	"testEncryption reports failure when crypto is unavailable");

# --- verifyNMISEncryption: reports failure, writes nothing, names packages ---
@writes = ();
my $out = '';
{
	local *STDOUT;
	open(STDOUT, '>', \$out) or die "cannot capture STDOUT: $!";
	my $rc = NMISNG::Util::verifyNMISEncryption(log => $logger);
	is($rc, 1, "verifyNMISEncryption reports failure (returns 1) when crypto is unavailable");
}
is(scalar(@writes), 0, "verifyNMISEncryption attempted no config write");
like($out, qr/Crypt::CBC/, "verifyNMISEncryption prints an operator message naming the crypto modules");
like($out, qr/libcrypt-cbc-perl/, "verifyNMISEncryption names the OS packages to install");

done_testing();
```

- [ ] **Step 4: Fix `encrypt` module-missing branch**

Replace the module-missing branch of `encrypt` (currently around lines 4868-4882):

```perl
	eval {require Crypt::CBC; require Crypt::Cipher::AES; require Math::Random::Secure;};
	if($@)
	{
		$logger->error("ERROR: 'Crypt::CBC' and 'Crypt::Cipher::AES', and 'Math::Random::Secure' must be installed in order to enable password encryption!");
		$logger->error("ERROR: Password encryption cannot be enabled!");

			$logger->error("ERROR: encryption was requested but the crypto modules are missing. The flag is left unchanged. Install the packages above.")
```
